# Workbench Operations

## Discover

Define the trigger, not-for boundary, inputs, outputs, modes, ownership, resources, and acceptance tests before creating files.

## Scaffold

Check all existing skill names first. Create one bounded tree and do not overwrite a collision.

## Distill

Keep the entry point short. Move reusable domain knowledge to references and reusable output shapes to assets.

## Restructure

Preserve behavior, public triggers, and ownership unless the approved change explicitly alters them. Produce a before/after resource map.

## Score and Audit

Run `scripts/creator_skill_workbench.py`, inspect every deduction, and provide remediation actions. A system or package audit must hand off to `creator-evidence-audit`.
