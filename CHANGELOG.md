# Changelog

All notable Creator Toolchain changes are documented here.

## [1.1.0] - 2026-09-01

### Added

- deterministic schema `0.4.0` workspace bootstrap and validation;
- atomic state transactions, optimistic locking, append-only ledgers, backup, and rollback;
- typed intake artifacts and a deterministic Planning Quality Gate;
- approved execution lifecycle with task-level verification evidence;
- mandatory reconciliation, summary, ledger, and state-update proposals;
- explicit recovery paths for interruption, failed verification, blocked work, scope creep, state divergence, and incomplete reconciliation;
- canonical ten-surface registry, evidence-derived Health, and owner-gated state reconciliation;
- staged rule proposals, immutable approval records, conflict detection, and seven implemented rule domains;
- deterministic workflow routing, Workbench scoring, and evidence-audit judgment contracts;
- rerunnable 34-case Behavior Acceptance with evidence spans and a writable Golden E2E;
- single-source versioning, atomic Plugin mirror replacement, unified release checks, clean installation, and exact seven-Skill discovery;
- operations guides and machine-readable final release status.

### Changed

- workspace schema upgraded from `0.3.0` to `0.4.0`;
- release confidence now depends on current commit- and payload-bound evidence;
- Plugin installation examples now use immutable tag `v1.1.0`;
- release requests route to deterministic scripts coordinated by `creator-orchestrator`.

### Compatibility

- existing `0.3.0` state can be migrated transactionally with byte-equivalent rollback;
- the seven-Skill architecture and public Skill names are preserved;
- no eighth core Skill, mandatory hook, MCP server, SaaS dependency, telemetry, or UI is introduced.

## [1.0.1] - 2026-06-29

- packaged seven Creator Toolchain Skills for Codex;
- established `.agents/skills/` as the authoritative development source;
- generated a byte-equivalent Plugin Skill mirror;
- validated exact runtime package contents and deterministic ZIP output;
- defined the initial Creator workspace state contract.
