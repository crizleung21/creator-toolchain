# Plugin Release Routing

## Primary Workflow

Plugin release and marketplace publication remain coordinated by `creator-orchestrator`. No eighth skill and no undefined phase workflow is introduced.

## Required Support

```text
scripts/release_creator_toolchain.py
```

The script is scheduled for Phase 8. Before it exists, the correct result is a capability-gap decision, not an improvised archive.

## Required Evidence

- approved release scope;
- current package-integrity report;
- current behavior acceptance evidence;
- green evidence-derived health;
- reproducible package build;
- clean-install and seven-skill discovery evidence;
- current CI result.

## Boundary

The orchestrator coordinates checks and handoffs. It does not bypass release gates, rewrite evidence, or publish directly when deterministic release support is absent.
