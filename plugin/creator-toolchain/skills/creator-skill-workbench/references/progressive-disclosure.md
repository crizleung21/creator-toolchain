# Progressive Disclosure

`SKILL.md` is the routing and operating entry point, not a complete knowledge dump.

## Keep in SKILL.md

- precise trigger and boundary;
- modes and core workflow;
- output contract;
- Mode-to-Resource Map;
- guardrails and acceptance tests.

## Move to references

- detailed procedures;
- domain frameworks;
- long examples;
- scoring or judgment definitions;
- migration and recovery detail.

## Move to assets

- reusable JSON, Markdown, YAML, or code templates.

A resource must be discoverable from the mode that needs it. Unreferenced resources are maintenance debt.
