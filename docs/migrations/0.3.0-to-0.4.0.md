# Creator State Migration — 0.3.0 to 0.4.0

## Current Phase 1 Status

Migration planning and backup generation are implemented. Live migration is intentionally gated until the next Phase 1 execution slice adds full repository fixtures, cross-file transformation rules, write verification, and rollback tests.

## Available Commands

```bash
python3 scripts/migrate_creator_state.py --root .
python3 scripts/migrate_creator_state.py --root . --plan /tmp/migration-plan.json
python3 scripts/migrate_creator_state.py --root . --backup /tmp/creator-state-backup
```

## Disabled Command

```bash
python3 scripts/migrate_creator_state.py --root . --write
```

The command exits with status `2` and performs no writes in this slice.

## Planned 0.4.0 Changes

- update `schema_version` from `0.3.0` to `0.4.0`;
- normalize legacy privacy values;
- add `created_at` where absent;
- refresh `updated_at`;
- preserve all existing records;
- validate cross-file references before commit;
- create a complete backup;
- restore the backup automatically if post-write validation fails.

## Next Gate

Live migration may be enabled only after:

1. the full current `.creator` state is represented by migration fixtures;
2. every surface transformation is covered by positive and negative tests;
3. rollback restores byte-equivalent source files;
4. the repository validator accepts schema `0.4.0`;
5. the migrated workspace passes all cross-file checks.
